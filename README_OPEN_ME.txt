ФОКУС — ГОТОВЫЙ ПРОЕКТ ДЛЯ 1-Й АТТЕСТАЦИИ
==========================================

В проекте ДВЕ настоящие Activity / ДВА экрана:
  1. «Мой день» — прогресс, быстрый доступ, задачи, карточка пары и кнопка добавления.
  2. «Все задачи» — интерактивный список с фильтрами, отметками выполнения, добавлением задач и статистикой.

Что делать:
  1. Распакуй ZIP в обычную папку, например D:\Projects\FocusPlanner.
  2. Android Studio -> File -> Open -> выбери папку FocusPlanner (не app!).
  3. Дождись Gradle Sync и загрузки SDK / Gradle (при первом открытии нужен интернет).
  4. В Device Manager запусти Android эмулятор (телефон, API 26+).
  5. Выбери конфигурацию «app» и нажми зелёный Run.
  6. Для второго экрана нажми вкладку «Задачи» внизу или «Все задачи» на главном экране.

Если Android Studio спрашивает Gradle JDK — выбери Embedded JDK 17 или выше.
Уточнение: AGP 8.7.3, Gradle 8.9, Kotlin 2.0.21, compileSdk 35. Без Compose и дополнительных библиотек.

При нажатии на задачу меняется статус и процент выполнения. Состояние сохраняется в SharedPreferences.
Кнопка «Новая задача» открывает диалог. Кнопки навигации переключают экран.

Для сдачи сделай два скриншота: 1) «Мой день», 2) «Все задачи», а исходники загрузи в облако или GitHub.
Дополнительная зависимость от интернета во время работы приложения НЕ нужна.
